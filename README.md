# IR-Scanner Heizstrahler

Ersatz-Fernbedienung für den Prima-Vista-Heizstrahler (Landi), für Handys mit IR-Sender (z. B. Honor 400 Pro).

## APK bauen über GitHub
1. Neues Repository auf github.com anlegen.
2. Den gesamten Inhalt dieses Ordners hochladen, auch den versteckten Ordner `.github`.
   (Unter Linux Mint versteckte Ordner mit Strg+H einblenden.)
3. Reiter «Actions» öffnen und warten, bis der Durchlauf grün ist (ca. 5 Min.).
4. Durchlauf anklicken, unten bei «Artifacts» die Datei «IR-Scanner-APK» herunterladen.
5. ZIP entpacken, `app-debug.apk` aufs Handy kopieren und installieren.

## Bedienung
1. Strahler einstecken, Handy-Oberkante auf das Gerät richten (1–2 m).
2. «Start» drücken. Phase 1 testet zuerst die häufigsten Gerätecodes.
3. Sobald der Strahler piepst oder angeht: «REAGIERT!» drücken.
4. In «Zuletzt gesendet» die Codes einzeln mit «Senden» testen.
5. Den richtigen Code mit «Speichern» als Taste ablegen (Ein/Aus, Stufen).
